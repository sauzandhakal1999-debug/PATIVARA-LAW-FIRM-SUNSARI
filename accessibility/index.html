Website Accessibility Statement

PATHIVARA LAW FIRM SUNSARI is dedicated to ensuring that our digital resources are accessible to individuals of all abilities, including users with visual, auditory, motor, or cognitive disabilities.

1. Standards & Conformance

This website is engineered to conform with the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA standards. Key features implemented include:

  • Keyboard Navigation: All interactive elements, forms, and navigation menus can be operated completely via keyboard (Tab, Enter, Escape).
  • Skip to Content Link: A dedicated skip link allows screen reader and keyboard users to bypass global navigation directly to main content.
  • High Contrast Color Palette: Deep Navy (#0d1b2a) on white/light neutral surfaces exceeds the 4.5:1 contrast ratio required for readable body text.
  • Semantic HTML5 Structure: Proper use of landmarks (<header>, <main>, <footer>, <article>, <section>) and strict logical heading hierarchies (H1 to H3).
  • Descriptive Form Labels: Every input field has explicit label associations and accessible status announcements.
